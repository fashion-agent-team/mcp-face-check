# 얼굴 분할 모델 비교 (2026-11-10)

눈썹·입술을 사진에서 나누는 얼굴 분할 모델을 여러 개 같은 조건으로 비교해서 고른 기록입니다.

## 결론

**BiSeNet ResNet34(yakhyo/face-parsing, fp16 47MB)로 바꿨습니다.**

- 분할 모델을 쓰는 4항목(눈썹 높이·길이·두께, 윗입술 선) 평균 검출률이 51.4%에서 53.3%로 올랐습니다.
- 같은 사진끼리 짝지어 보면 새로 잡은 것이 98장, 놓친 것이 67장입니다(부호 검정 p=0.019). 우연으로 보기 어려운 차이입니다.
- 가장 많이 나아진 것은 가장 약했던 눈썹 길이입니다. 평균 18%에서 22%가 됐고, 중간 크기는 8%에서 18%가 됐습니다(새로 잡음 24, 놓침 8, p=0.007).
- 대신 한 장에 50ms쯤 더 걸립니다(86ms → 136ms). 앱이 3~5장을 보내므로 요청 하나가 0.15~0.25초 늘어납니다.
- ResNet18 다른 학습본은 그전 모델과 차이가 없었습니다(p=0.73).

재지 못한 모델:

- **FaRL**: 모델 파일이 646MB라 GitHub 파일 한도(100MB)와 서버 메모리에 맞지 않습니다. 또 TorchScript 파일이라 받은 코드를 실행해야 해서, 이 개발 환경에서는 안전 규칙상 돌리지 않았습니다. 그래서 정확도는 재지 못했습니다.
- **SegFormer**: 개발 환경에서 Hugging Face 접속이 막혀 받지 못했습니다.

## 속도·크기

컨테이너 CPU 4코어, onnxruntime, 서버와 같은 입력(1×3×512×512), 15번 돌린 가운데 값입니다.

| 모델 | fp16 크기 | fp16 한 장 | fp32 크기 | fp32 한 장 | 서버 메모리(RSS, fp16) |
| --- | --- | --- | --- | --- | --- |
| ResNet18 (그전) | 26.3MB | 86ms | - | - | - |
| ResNet18 (다른 학습본) | 26.6MB | 88ms | 53.2MB | 78ms | 655MB |
| **ResNet34** | **46.9MB** | **136ms** | 93.6MB | 122ms | 679MB |

fp32가 조금 빠르지만 ResNet34 fp32는 93.6MB로 GitHub 파일 한도에 가까워서 fp16을 넣었습니다. 두 버전은 분류 결과가 거의 같습니다.

## 정확도(검출률)

`training/public_baseline.py`와 같은 방법입니다. CelebA 화장한 얼굴 2,832장에 한쪽만 다르게 그려 넣고 몇 %를 잡는지 봤습니다.
모델마다 그려 넣지 않은 사진의 95%가 기준 아래가 되도록 기준을 따로 잡았습니다. 그래서 오탐은 모두 5%로 같습니다.
분할 모델을 쓰지 않는 항목(볼 색, 입술 색, 입술 너비)은 세 모델이 똑같았습니다.

| 항목 | 모델 | 중간 크기 | 가장 큼 | 다섯 구간 평균 |
| --- | --- | --- | --- | --- |
| 눈썹 높이 | 그전 / R18 / **R34** | 94% / 93% / **91%** | 100% / 100% / **100%** | 72% / 72% / **72%** |
| 눈썹 길이 | 그전 / R18 / **R34** | 8% / 14% / **18%** | 42% / 38% / **42%** | 18% / 19% / **22%** |
| 눈썹 두께 | 그전 / R18 / **R34** | 45% / 48% / **47%** | 55% / 50% / **56%** | 40% / 40% / **43%** |
| 윗입술 선 | 그전 / R18 / **R34** | 86% / 91% / **88%** | 94% / 95% / **94%** | 75% / 77% / **77%** |

같은 사진끼리 짝지은 비교(그전 모델 대비, 4항목 합):

## 다시 해 보는 법

1. 모델 만들기:
   - 지금 모델: `python3 training/fetch_face_parsing_r34.py`
   - 그전 모델: `python3 training/export_face_parsing.py`
2. 속도: `python3 training/compare_face_parsing.py speed <onnx 파일들>`
3. 검출률:
   - 모델마다 서버를 `--face.parsing.model=file:<onnx>`로 띄웁니다.
   - `public_baseline.py <CelebA> --n 5000`(`--apply` 없이)을 돌리고, `out/public_baseline.json`을 모델별로 복사합니다.
   - `python3 training/compare_face_parsing.py detect 그전=a.json r34=b.json`

## 한계

- 평가 사진은 CelebA이고, 비교한 모델은 모두 CelebAMask-HQ(CelebA에서 고른 사진)로 학습했습니다. 그래서 실제 셀카보다 점수가 좋게 나올 수 있습니다. 다만 세 모델이 같은 조건이라 순위 비교에는 문제없습니다.
- CelebAMask-HQ는 비상업 연구용 데이터입니다. 그전 모델과 같은 조건입니다.
- 속도는 컨테이너 CPU 기준입니다. 실제 서버 CPU에서는 달라질 수 있습니다.
